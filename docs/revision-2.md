# 수정 2 — 인터넷 사용 금지와 다국어 UI

명세만 수정했다. EXE 구현·빌드·실행 시험은 수행하지 않았다.

## 채택한 변경과 근거

- [사용자 요청, 채택] 인터넷 없이 실행 가능하다는 조건을 앱과 호스팅한 렌더러가 인터넷 요청 자체를 시도하지 않는 조건으로 강화했다. 원격 본문 리소스, 업데이트, 통계, 온라인 번역과 외부 브라우저 호출에 적용한다.
- [사용자 요청, 채택] 앱 UI에 한국어·영어·프랑스어·일본어를 제공하고 번역 데이터를 EXE에 포함한다. 언어 변경 버튼을 추가한다.
- [사용자 확인 답변, 채택] 매 실행 Windows 로캘이 ko·en·fr·ja이면 해당 언어를 쓰고 그 외에는 영어를 사용한다.
- [사용자 확인 답변, 채택] 버튼으로 선택한 언어는 현재 실행에서만 유지하고 앱 종료 후에는 저장하지 않는다. 다음 실행은 다시 Windows 로캘을 따른다.
- [대안, 미채택] 최초 실행을 항상 한국어로 고정하는 방식, 언어 설정을 별도 파일이나 레지스트리에 저장해 다음 실행에도 유지하는 방식.
- [일반 예외 처리] 로캘 조회가 실패하면 한국어 기본 리소스를 사용한다. 이 예외 처리 기본값을 별도의 사용자 지정 요구로 표시하지 않았다.

두 확인 답변이 도착하기 전 기록한 기본안은 사용자의 답변으로 확정했고, 미확정 표시를 제거했다. 새로운 인터뷰나 MCP 세션을 만들지 않았다.

## 이전 명세와의 차이

- 기존 `seed_id`와 ontology를 유지하면서 `viewer_session` 설명에 로캘·선택 UI 언어를 반영했다.
- AC-09에 인터넷 요청 금지, AC-10에 다국어 UI를 추가하고 종료 조건의 검증 범위를 갱신했다.
- `localization_policy`에 시작 언어, 수동 변경, 실행 중 유지, 번역 범위를 명시했다.
- `SPEC.md`에 언어 매핑표와 연결 가능한 PC에서 통신 시도를 확인하는 검증 계획을 추가했다.
- 구현 언어가 미지정이라는 기존 문구를 UI 언어와 혼동하지 않도록 명확히 했다.
- 단일 EXE, 7~8MB 목표, 속도 우선, 본문 표현과 첨부 저장·정리 조건은 유지했다.
- 이전 명세·QA·평가 기록은 `history/revision-1/`에 보존했다. 이전 평가를 수정 2의 통과 결과로 재사용하지 않는다.

## QA와 검증

수정 2의 로컬 QA 1/5회차: **0.97, pass**. 필수 수정 제안은 없었다. 정확한 결과는 `seed-qa.json`에 기록했다.

기계적 검사에서 추가 메타데이터의 날짜가 YAML 날짜 객체로 파싱되는 문제를 발견해 `provenance.revised_at`을 문자열로 인용했다. 요구사항 변경 없이 수정했으며 재검증 후 설치된 Ouroboros Seed 모델 검증, AC-01~10 식별자, 기존 seed ID, 언어 목록, 미결정 사항 없음 및 이전 스냅샷 해시 검사가 통과했다. 최종 파일 해시는 `seed-mechanical.json`과 `seed-audit.json`에 기록했다.

QA는 문서에 대한 독립 로컬 검토다. 인터넷 무통신, 다국어 GUI, 최종 EXE 크기와 성능의 실제 동작 시험은 구현 후 수행해야 한다.
