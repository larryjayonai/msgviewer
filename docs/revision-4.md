# 수정 4 — x86 유지와 화면 배치 확정

사용자는 x64 전용의 이점을 검토한 뒤 원래의 x86 공용 EXE를 유지하고 아래 화면 배치를 직접 지정했다. 이번 작업은 명세 수정이며 실행 프로그램을 구현하거나 빌드한 작업이 아니다.

## 확정한 배치

1. 최상단 왼쪽 열기·닫기, 오른쪽 언어 변경·종료.
2. 그 아래 보내는 사람과 메시지 전송 일시를 같은 줄에 표시. 일시는 연·월·일·시·분·초 정밀도.
3. 받는 사람, 참조, 숨은참조를 이 순서로 각각 한 줄씩 표시.
4. 제목은 기본 한 줄이며 길면 두 줄·세 줄 등으로 줄바꿈.
5. 제목 아래 본문.
6. 맨 아래 첨부파일 섹션에 일반 첨부의 파일명을 한 줄에 한 파일씩 표시. 일반 첨부가 없으면 한국어 UI에서 없음, 다른 UI 언어에서는 해당 번역 표시.

이전의 본문 삽입·서명·로고 이미지 목록 제외, 일반 이미지 파일 첨부 유지, 첨부 이름 클릭 시 저장만 제공, 바탕화면 기본 저장 위치, 텍스트 선택·우클릭 복사를 유지했다.

## 구현 기본값과 정합성

전송 시각 표현은 24시간제 `YYYY-MM-DD HH:mm:ss`, 시간대는 원본 근거를 확인해 실행 PC의 Windows 시간대로 표시하는 기본값으로 정리했다. 사용자에게 지정받은 시간대라고 기록하지 않았다.

MSG에 없는 숨은참조나 전송 시각은 정보 없음으로 표시한다. 실제 숨은참조 수신자가 없었다고 단정하거나 파일 생성·수정 시각을 메시지 전송 시각으로 대체하지 않는다. 긴 주소는 한 줄에서 전체 확인·선택·복사가 가능하게 하고 제목을 세 줄에서 잘라내지 않는다. 이 처리는 사용자 데이터의 정확성과 기존 선택·복사 동작을 유지하기 위한 지침이다.

## 변경 및 검증 기록

- AC-02, AC-05, AC-11에 배치를 반영하고 `layout_policy`와 상세 배치 예시를 추가했다.
- 기존 seed ID, 11개 AC, 6개 ontology 필드를 유지하고 메일 기본정보 설명에 숨은참조와 초 단위 전송 시각을 반영했다.
- 수정 3의 명세·QA·감사 기록을 `history/revision-3/`에 보존하고 기존 해시와 일치함을 확인했다.
- 설치된 Ouroboros 0.51.7 Seed 스키마, 중복 키, AC 식별자, x86 유지, 버튼·본문 순서, 초 단위 표시, ontology 보존 및 텍스트 검증을 통과했다.
- 독립 로컬 명세 QA 1/5회차 **0.98, pass**. 필수 수정 제안은 없다.

최신 파일 해시와 검토 결과는 `seed-mechanical.json`, `seed-qa.json`, `seed-audit.json`에 기록했다. 명세 검증은 실제 GUI·EXE 크기·속도·OS별 실행 검증을 대신하지 않는다.
