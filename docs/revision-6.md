# 수정 6 — 버전 1.1 (단축키, 언어 순환, 버튼 복원 및 빈 필드 없음 표기)

기존 완료본(수정 5)을 **버전 1.0 (v1.0)**으로 정의하고, 이번 수정 6을 반영한 결과물을 **버전 1.1 (v1.1)**로 지정한다.

## 1. 확정된 변경 명세

### 1) 단축키 및 버튼 명칭
- **열기 (F2)**:
  - 버튼 명칭: `열기 (F2)` / `Open (F2)` / `Ouvrir (F2)` / `開く (F2)`
  - 단축키: `F2` 키 입력 시 파일 열기 대화상자(`OpenFileDialog`) 즉시 호출.
- **닫기 (F4)**:
  - 버튼 명칭: `닫기 (F4)` / `Close (F4)` / `Fermer (F4)` / `閉じる (F4)`
  - 단축키: `F4` 키 입력 시 현재 열린 문서 및 임시자원 정리 후 초기화.
- **언어 변경 (F8)**:
  - 버튼 명칭: **`언어 / Language / Langue / 言語 (F8)`** (UI 언어와 무관하게 고정 문구 유지)
  - 단축키 `F8` 입력 시 동작: **다음 언어로 즉시 순환(Cycle) 전환**
    - 순환 순서: `한국어` → `English` → `Français` → `日本語` → `한국어` → ...
    - 별도 메뉴 팝업 없이 전체 UI 텍스트(버튼, 레이블, 빈 필드 및 첨부의 '없음') 즉각 갱신.
  - 마우스 클릭 시 동작 (**안 B** 채택):
    - 언어 버튼 클릭 시 기존 4개 언어 선택 메뉴(`한국어 / English / Français / 日本語`) 팝업 유지.
- **종료**: 기존 명칭 및 `Alt+F4` 유지.
- **전역 단축키 처리**: `KeyPreview = true`를 통해 폼 내 포커스 위치와 무관하게 F2, F4, F8 입력 즉각 감지.

### 2) 언어 버튼 상태(Pressed / Sunken) 정상화
- 언어 버튼 클릭 후 드롭다운 메뉴가 열리거나 닫힌 뒤에도 버튼이 눌린(pressed/sunken) 상태로 남아있던 현상 수정.
- 메뉴가 표시되거나 닫힐 때(`Closed`), 그리고 언어 선택 완료 시 버튼의 마우스 캡처 및 포커스 상태를 해제하여 항상 평상시 돌출(Normal/Raised) 버튼 상태로 즉시 복원.

### 3) 빈 필드(`받는 사람`, `제목`) "없음" 표기
- 대상: **받는 사람(`To`)**, **제목(`Subject`)**
- 메일 데이터에서 해당 필드가 비어 있거나 공백인 경우, 첨부파일 없음과 동일하게 언어별 `None` 리소스 문자열로 표시:
  - 한국어: `없음`
  - English: `None`
  - Français: `Aucun`
  - 日本語: `なし`
- 메일 열람 중 `F8` 또는 메뉴로 언어를 변경하면 빈 필드의 텍스트도 새 언어의 번역어로 즉시 갱신.
- 메일이 닫혀 있는 초기 빈 상태에서는 빈 문자열(`""`) 유지. (참조 `Cc`는 기존 빈칸 유지)

## 2. 버전 및 검증
- 기존 v1.0의 단일 x86 EXE 배포, 7~8MB 이하 크기 유지, 완전한 오프라인 격리 정책을 동일하게 계승.
- 버전 식별자: **v1.1** (AssemblyVersion 1.1.0.0).
