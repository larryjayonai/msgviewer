# 수정 5 — 언어 버튼 문구 고정

사용자의 명시 요청에 따라 언어 변경 버튼을 `언어 / Language / Langue / 言語`로 고정했다. UI 언어와 관계없이 네 단어와 구분자를 한 버튼에 표시한다. 기존 상단 오른쪽, 종료 버튼 바로 왼쪽 위치를 유지한다.

AC-10, toolbar_right, localization_policy, SPEC의 배치 예시·번역 예외·검증 계획을 갱신했다. 버튼을 누른 뒤 선택하는 언어 이름은 `한국어 / English / Français / 日本語`를 유지한다. 다른 UI 문구의 번역과 기존 동작은 그대로다.

직전 명세와 검토 기록은 `history/revision-4/`에 보존했다. 설치된 Seed 모델의 스키마 검사와 정확한 문구·배치·선택 항목 검사를 통과했다. 독립 로컬 변경 QA는 1/5회차 0.99, pass다. 실제 앱 구현·실행 검증은 수행하지 않았다.
